# Soroush Fathi — Personal website

A lightweight, responsive personal site for [soroushfathi.github.io](https://soroushfathi.github.io).

The site is intentionally framework-free: semantic HTML, modern CSS, and a small JavaScript theme toggle. Content is based on Soroush's current product and software engineering work, with project links pointing to their canonical public pages.

## Run locally

From this directory, start any static file server. For example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

GitHub Pages publishes the `main` branch of this repository.
